# ClaudeUsage

Claude, Codex, Antigravity 사용량을 확인하는 macOS 메뉴바 앱입니다. 서비스별 사용량 한도와 갱신 예상 시각을 한곳에서 확인할 수 있습니다.

Anthropic, OpenAI, Google과 제휴하지 않은 독립 프로젝트입니다.

## 설치

- macOS 14 이상, Apple Silicon 및 Intel Mac 지원
- [최신 안정 버전과 변경 사항](https://github.com/ChoSeongmin1128/claude-usage/releases/latest)

Homebrew Cask로 설치할 수 있습니다.

```bash
brew install --cask choseongmin1128/tap/claude-usage
```

DMG 설치는 다운로드한 DMG를 열고 앱 아이콘을 Applications 아이콘으로 드래그한 뒤, Finder의 Applications 폴더에서 앱을 실행합니다. DMG 안의 앱을 직접 실행하면 설치 위치 안내만 표시하며 앱을 자동으로 복사하거나 DMG를 삭제하지 않습니다. Homebrew 설치본에서도 앱 자체 업데이트가 동작합니다.

기존 수동 설치본을 Homebrew 관리로 바꾸려면 먼저 최신 운영 버전으로 업데이트하고 ClaudeUsage를 종료한 뒤, 기존 앱 번들만 휴지통으로 옮기고 위 명령을 실행합니다. 설정·계정 데이터는 앱 번들 밖에 유지됩니다. 기존 앱을 확인 없이 등록할 수 있는 `--adopt`는 사용하지 않습니다. 자세한 절차는 [Homebrew 배포 안내](docs/homebrew-distribution.md#기존-설치본-편입)를 참고하세요.

## 주요 기능

- 서비스별 사용량·남은 양·갱신 예상 시각 표시
- 현재 사용량 창과 주간 한도, 서비스가 제공하는 추가 quota 표시
- 배터리·원형·동심원 등 메뉴바 아이콘과 팝오버 표시 항목 설정
- 계정별 조회 경로와 인증 상태 확인
- 사용량 임계치 알림과 사용 상황에 맞춘 자동 확인 간격
- 서명된 업데이트 안내, 백그라운드 다운로드와 사용자 선택에 따른 설치

설정 → 표시의 ‘표시 기준’에서 사용한 양·남은 양을 선택하면 메뉴바, 팝오버, 알림 문구가 같은 기준을 사용합니다. 신규 설치는 남은 양으로 시작하며, 기존 사용자는 공통 기준을 선택하기 전까지 이전 서비스별 표시와 알림 기준을 유지합니다. 색상은 사용한 양을 기준으로 주의 단계를 나타내며, 배터리·원형·동심원·이중 배터리에서 같은 기준을 사용합니다. 추가 결제 사용량처럼 금액으로 표시하는 항목은 지출액을 그대로 표시합니다.

설정 → 표시의 시간 형식은 초기화 시각 24시간(18:34), 12시간(오후 6:34), 남은 시간 단위 표시(2h 34m / 3d 2h) 세 가지입니다. 선택 메뉴에 실제 예시를 함께 보여줍니다. Claude의 5시간 초기화 시각을 알 수 없으면 주간 시각을 대신 표시하지 않습니다.

팝오버의 사용량, 추가 사용량, 크레딧과 초기화권은 같은 열 기준을 사용합니다. 일반 화면에서는 제목과 주값을 같은 줄에 놓고 시간·금액 설명은 아래에 표시합니다. 간소화 화면은 같은 열 기준을 한 줄 안에서 사용합니다. Codex 숫자 잔액은 `62,495.73 남음`처럼 표시하며, 무제한이나 정보 없음은 상태 문구로 표시합니다. 퍼센트의 자릿수가 달라져도 사용량 막대의 폭과 숫자의 정렬 위치는 유지됩니다.

팝오버의 기본 순서는 5시간, 주간, 모델별 한도, 크레딧, 초기화권입니다. 표시 항목과 순서는 사용자가 바꿀 수 있습니다. 기본 순서로 쓰던 기존 설치도 초기화권을 맨 아래로 옮기며, 직접 정한 순서와 숨김 설정은 유지합니다. 팝오버의 편집 버튼은 해당 서비스 설정을 바로 엽니다.

Codex 설정은 조회된 계정에서 제공하는 한도와 표시 항목만 보여줍니다. 개인 플랜에는 조직의 월 사용 한도가 나오지 않습니다. 크레딧 잔액은 개인 플랜에서도 표시할 수 있으며, 잔액이 0이어도 표시 여부를 설정할 수 있습니다. 계정에 따라 항목이 숨겨져도 저장한 순서와 표시 여부는 유지됩니다.

설정 → 표시에서 메뉴바의 클래식·새 디자인을 선택할 수 있습니다. 기존 사용자는 클래식을 유지하고 새 디자인을 한 번 안내받으며, 신규 설치자는 새 디자인으로 시작합니다. 색상·표시 항목·사용률/잔여율 설정은 유지됩니다.

설정 → 표시 → 모션에서 즉시·부드러움·사용자 설정을 선택합니다. 사용자 설정에서는 팝오버 열기·닫기와 크기 전환, 설정 탭·시작하기 단계, 상세 접기·펼치기, 표시 항목 이동·숨기기, 사용량 막대 갱신을 각각 조정할 수 있습니다. 기본값은 즉시입니다. macOS의 ‘동작 줄이기’가 켜져 있으면 선택을 막고 손쉬운 사용 설정으로 가는 버튼을 보여줍니다(macOS 26 이상은 손쉬운 사용 > 동작, 14·15는 손쉬운 사용 > 디스플레이). ‘모션 비교’에서 동작 하나를 선택해 두 방식을 비교합니다. 개별 항목은 사용자 설정에서만 보이고, 미리보기는 저장된 설정을 바꾸지 않습니다.

각 서비스 설정에서 계정 연결, 메뉴바, 한도별 숫자와 알림, 팝오버 항목을 관리합니다. 한도 표는 메뉴바 숫자와 알림을 고르고, 팝오버의 표시 여부와 순서는 아래 ‘팝오버 항목과 순서’에서 정합니다. 게이지 모양과 대표 한도는 같은 페이지의 ‘메뉴바 표시’에서 정합니다. ‘알릴 시점’은 표시 방식이 바뀌어도 같은 조건을 유지합니다. 예를 들어 사용 85%는 남음 15%로 표시됩니다. 알림 칸에서 실제 조회된 시간·모델별 한도를 알림 대상으로 선택할 수 있습니다. Claude의 모델별 한도와 Codex의 플랜별·추가 모델 한도, Antigravity의 한도를 지원하며 크레딧 잔액·초기화권 개수는 제외합니다. 첫 응답에 빠졌던 기존 Claude·Codex 기본 5시간·주간 한도는 이후 응답에서 알림 선택 이전을 이어갑니다. 직접 끈 항목과 새 모델·주기는 자동으로 켜지 않습니다. 제공자별 이전 예외는 [업데이트 호환 안내](docs/upgrade-compatibility.md)를 따르며, 표시 숨김과 알림 선택은 독립적입니다.

Claude와 Codex가 한도 초기화권을 주면 팝오버에 개수, 지우는 범위(전체 한도 또는 5시간 한도만), 만료까지 남은 시간을 보여줍니다. 서버가 붙인 이름은 행에 마우스를 올리면 보입니다. 앱은 초기화권을 읽기만 하며 사용하지 않습니다. 메뉴바에는 수치 옆에 ↺1처럼 개수를 표시할 수 있고(각 서비스 설정의 초기화권 줄에서 항상/신규나 곧 만료일 때만/끔), 새로 받은 것은 파란색, 48시간 안에 만료되는 것은 빨간색으로 표시합니다. 새로 설치하면 항상, 업데이트한 사용자는 끔으로 시작합니다. Codex 초기화권은 설치된 Codex의 공식 app-server에서 5분마다 읽습니다.

계정 상세와 고급 진단은 제목 행을 눌러 펼칩니다. 계정의 ‘사용’ 버튼은 상세 펼침과 별도로 동작합니다. ‘전체 스타일 비교’를 펼치면 다섯 게이지 모양의 클래식·새 디자인을 나란히 볼 수 있습니다. 메뉴바 직접 설정은 실제 미리보기와 로고·게이지·숫자·초기화 시간으로 구분하며 창 폭에 맞춰 배치됩니다.

처음 실행하면 시작하기 화면이 Claude, Codex, Antigravity마다 찾은 상태와 바로 할 일 하나를 보여줍니다. Claude는 Claude Code 로그인, 기본 브라우저나 Claude 앱의 로그인 가져오기, 브라우저에서 새로 로그인(로그인하면 앱이 알아서 가져옴), 앱에서 로그인 순으로 권합니다. Codex와 AGY CLI는 로그인돼 있으면 바로 연결하고, 없으면 설치 방법을 안내합니다. 연결한 뒤 메뉴바 설정으로 넘어갑니다. 나중에 설정할 수도 있으며, 마칠 때까지 설정 사이드바의 ‘시작하기’에서 다시 이어갈 수 있습니다. 업데이트 후에는 새 기능이 있는 버전만 짧은 안내를 한 번 보여주며, 설정 → 업데이트의 ‘새 기능 다시 보기’로 다시 볼 수 있습니다.

자동 확인은 팝오버를 막 열었거나 Claude Code·Codex를 쓰는 중이거나 한도가 10% 이하로 남으면 2분마다, 오래 쓰지 않으면 최대 30분 간격으로 합니다. 팝오버를 열 때 마지막 확인이 2분보다 오래됐으면 바로 확인합니다. 팝오버의 새로고침 버튼과 `⌘R`은 선택한 서비스만 갱신합니다. 갱신 중이거나 방금 갱신한 직후(10초), 서버가 요청한 재시도 대기 시간에는 버튼이 비활성화되고 남은 시간을 알려줍니다. 추가 사용량도 같은 계정의 일시적 실패에는 마지막 값과 확인 시각을 보존합니다.

Claude 또는 Codex 설정에서 ‘여러 계정 함께 보기’를 켜면 그 서비스 계정 여러 개의 한도를 팝오버에서 함께 봅니다(골라 보기, 대표 카드와 목록, 요약과 목록). 기본은 단일 계정입니다. 메뉴바와 팝오버 큰 카드는 계정 ⋯ → 메뉴바에 표시로 고른 계정 하나이며, 웹이나 Claude 앱 로그인도 고를 수 있습니다. 고르기 전에는 Claude 앱 로그인을 먼저 보여줍니다. 같은 계정은 계정과 조직이 같을 때 한 줄로 합치고 기본 로그인, CLI, 웹 배지를 붙이며, 메뉴바 계정에는 사용 중을 붙입니다. Claude는 `~/.claude-이름` 같은 CLAUDE_CONFIG_DIR 폴더도, Codex는 `~/.codex-이름` 폴더와 앱이 만든 폴더(공식 `codex login --device-auth`)도 찾습니다. 쓰지 않는 계정은 5분마다 확인합니다. 계정 ⋯ → 이 계정으로 전환은 기본 로그인과 그 계정 폴더의 로그인을 맞바꾸며, 바꾼 뒤 확인해 다르면 되돌립니다.

## 계정 연결

| 서비스 | 시작 방법 | 조회 방식 |
|---|---|---|
| Claude | 브라우저에서 가져오기(Chrome, Brave, Edge, Whale, Vivaldi, Chromium, Firefox, Safari, Claude 앱)·앱에서 로그인 또는 Claude Code | 웹 세션과 Claude Code OAuth |
| Codex | Codex CLI에 로그인한 뒤 서비스 활성화 | CLI의 OAuth 자격증명으로 사용량 조회 |
| Antigravity | AGY CLI에 로그인한 뒤 서비스 활성화 | AGY CLI의 현재 로그인 계정 |

서비스를 활성화하고 계정을 선택한 뒤 새로고침합니다. 명시적으로 계정을 바꾸거나 응답 계정이 다르면 이전 계정의 수치를 표시하지 않습니다. 일시적인 조회 실패에는 마지막 성공 값과 확인 시각을 유지하며, 실패를 0%로 바꾸지 않습니다.

Antigravity는 AGY CLI만 조회합니다(독립 앱은 공식 사용량 경로가 없어 2.8.0부터 조회하지 않음). 로그인 변경은 AGY CLI에서 진행합니다. AGY CLI는 조회할 때마다 공식 사용량 보고(`agy -p /usage`)를 낮은 우선순위로 한 번 실행하며, 확인하는 동안에도 이전 값을 그대로 보여줍니다. 이 보고는 quota를 쓰지 않고 보고와 함께 종료됩니다. 보고에는 계정 정보가 없어 CLI에 현재 로그인한 계정의 사용량을 표시합니다. Google 계정 연결과 Antigravity IDE는 지원하지 않습니다.

Antigravity는 응답에 있는 quota만 표시합니다. 계정마다 한도의 종류와 주기가 다를 수 있습니다. AGY CLI 1.1.11 이상이 필요하며, 공식 AGY 설치·업데이트는 다음 조회에서 재검증하므로 앱을 재시작할 필요가 없습니다.

인증과 데이터 출처의 상세 계약은 [인증 안내](docs/authentication-and-sources.md)와 [Antigravity 소스 설명](docs/antigravity-usage-sources.md)을 참고하세요.

## 개인정보와 진단

자격증명은 로컬 Keychain 또는 해당 CLI의 저장소에서 읽습니다. 계정 선택과 자격증명의 출처를 대조하며, 자동 조회 중 인증 창을 반복해서 띄우지 않습니다. 사용자가 직접 요청한 연결·가져오기에는 인증이 필요할 수 있습니다.

Antigravity 앱의 CSRF 토큰은 검증한 앱 프로세스에서만 읽어 메모리에서만 사용합니다. AGY CLI 사용량 보고는 AGY가 스스로 로그인 정보를 읽으며, 백그라운드 조회가 브라우저 로그인 창을 열거나 AGY에 등록한 MCP 서버를 실행하지 않습니다. 사용자가 실행한 AGY나 Antigravity 앱은 종료하지 않습니다.

사용량 진단에는 고정 오류 코드, 조회 경로, 소요 시간을 기록합니다. 별도의 메뉴바 진단에는 실행 채널·앱 경로, 아이콘 생성 상태와 창·화면 좌표를 기록합니다. 토큰·계정 주소·원본 인증 응답은 기록 대상이 아닙니다. 진단 로그를 공유할 때는 앱 경로에 포함될 수 있는 사용자 이름도 확인하세요. 사용량 조회는 각 서비스의 서버 또는 검증된 로컬 프로세스에 직접 요청합니다.

## 업데이트

Sparkle이 30분마다 운영 업데이트를 확인하고 다운로드·검증을 준비합니다. 설치는 사용자가 선택할 때 적용됩니다. 설정 → 업데이트에서 버전별 변경 사항과 설치 상태를 확인할 수 있습니다.

업데이트 DMG와 feed의 서명을 확인하며, 별도 ZIP 다운로드는 서명된 feed의 SHA-256과 대조합니다. 검증에 실패하면 설치를 중단하며, 수동 복구에는 최신 안정 버전 DMG를 사용합니다.

과거 버전의 설정 이전과 업데이트 예외는 [업데이트 호환 안내](docs/upgrade-compatibility.md)를 참고하세요.

## 개발

- Swift 6 언어 모드, Complete 동시성 검사
- Swift 6.2 이상을 지원하는 Xcode. 현재 검증 도구체인: Xcode 27.0
- SwiftUI, AppKit, URLSession, Sparkle 2.10
- ShellCheck 0.11.0과 Xcode 내장 swift-format

```bash
git clone https://github.com/ChoSeongmin1128/claude-usage.git
cd claude-usage
xcodebuild -project ClaudeUsage.xcodeproj -scheme ClaudeUsage   -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build
```

로컬 실행·서명 배포에는 개발자의 서명 설정이 필요합니다. 공식 배포용 개인키나 로컬 계정 설정은 저장소에 포함하지 않습니다.

## 알려진 제한

- 서비스의 인증·사용량 인터페이스가 바뀌면 추가 대응이 필요할 수 있습니다.
- AGY CLI 사용량 보고에는 계정 정보가 없어, CLI 대상에서는 로그인 계정 주소를 표시하지 않습니다.
- 메뉴바 아이콘이 보이지 않으면 macOS의 앱별 표시 설정과 사용 중인 메뉴바 관리 앱의 숨김 설정을 확인하세요. 설치 앱은 Finder에서 직접 실행하세요. 2.6.0에서는 숨김 상태이거나 팝오버를 열 위치를 확인할 수 없을 때 앱을 다시 열면 설정창을 표시합니다. 위치 정보만으로 시스템 차단을 단정하거나 아이콘을 재생성하지 않습니다.
