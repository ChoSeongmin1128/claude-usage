# 2.5.0

## 업데이트와 안정성 개선

- 계정 정보 확인과 화면 갱신의 동시 작업을 더 엄격하게 검증하도록 개선했습니다.
- 메뉴바 아이콘은 생성 시점의 화면 테마를 사용해 일관되게 그립니다.
- AGY 조회와 업데이트 실패 원인을 계정 정보 없이 진단할 수 있도록 개선했습니다.
- 서명된 업데이트 안내와 DMG 업데이트의 게시 완료 확인을 개선했습니다.
- 프로젝트 문서를 공개 사용 안내 중심으로 정리하고 MIT 라이선스와 외부 구성 요소 고지를 추가했습니다.

## 알려진 제한

- 이 버전은 staging 검증용이며 운영 앱을 교체하지 않습니다.
- AGY의 초기 인증이 지연되는 경우 마지막 사용량이 표시될 수 있으며, 새로고침으로 다시 확인할 수 있습니다.
