# 2.9.5

- 메뉴바 아이콘 우클릭 메뉴에서 각 서비스의 하위 메뉴에 '사용량 보기'와 '서비스 상태 보기'를 둡니다. 팝오버에서 고른 서비스와 관계없이 Claude와 Codex의 페이지를 모두 열 수 있습니다.
- 우클릭 메뉴에 '업데이트 확인...'을 추가했습니다. 설정의 업데이트 화면을 열고 바로 새 버전을 확인합니다.
- 설정의 업데이트 화면을 열 때마다 새 버전을 확인합니다. 결과는 확인 창 없이 업데이트 화면에만 표시하며, 이미 확인 중이면 다시 확인하지 않습니다.
- 업데이트를 내려받은 뒤 설치 준비가 끝날 때까지 '설치 준비 중'을 계속 보여 주고, 그동안 '지금 확인'을 누를 수 없게 했습니다. 잠깐 '지금 확인'만 남던 문제를 고쳤습니다.
