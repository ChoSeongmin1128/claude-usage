# 2.5.1

## Antigravity 조회와 설정 개선

- 조회 대상을 AGY CLI와 Antigravity 독립 앱으로 구분했습니다. 로그인 계정은 선택 메뉴 대신 읽기 전용으로 표시합니다.
- 해당 제품에서 로그인을 변경한 뒤 새로고침하면 확인된 계정과 사용량을 함께 갱신합니다.
- 선택한 제품의 조회가 실패해도 다른 제품의 계정으로 전환하지 않습니다.
- 조회 도중 로그인 계정이 바뀌면 다시 검증하고, 이전 계정의 수치가 섞이지 않게 했습니다.
- 수치형 사용량을 제공하지 않던 Google 계정 연결을 제거했습니다.
- 대상 변경과 자동 조회가 겹칠 때 잘못된 오류가 나타나던 문제를 수정했습니다.
- 기존 표시 설정은 유지합니다. 조회할 제품이 불명확한 구버전 설정은 업그레이드 후 대상을 한 번 선택하도록 안내합니다.

## 알려진 제한

- Antigravity IDE는 아직 지원하지 않습니다.
- 일부 초기 배포본은 현재 채널과 앱 식별자가 다릅니다. 자동 업데이트가 되지 않으면 공식 설치 안내를 확인해 주세요.
- 계정은 확인돼도 서비스가 quota를 제공하지 않으면 사용량 수치를 표시할 수 없습니다.
- 이 버전은 staging 검증용입니다.
