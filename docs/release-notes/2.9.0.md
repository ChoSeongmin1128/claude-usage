# 2.9.0

- 메뉴바 게이지를 세 개 이상 표시할 수 있습니다. Claude의 Fable, Codex 추가 모델, Antigravity에서 조회된 한도도 고를 수 있습니다.
- 서비스 설정의 한도 표에서 게이지를 체크하고, 바로 아래 목록에서 순서를 바꿉니다. 숫자와 초기화 시간은 각각 따로 고릅니다.
- 배터리 또는 원형을 선택할 수 있으며, 세 개 이상은 한도 이름을 붙여 가로로 표시합니다. 많이 선택하면 다른 메뉴바 항목이 가려질 수 있습니다.
- 기존 한 개/두 개 게이지의 크기, 배치와 선택은 유지합니다. Claude/Codex의 두 개 게이지는 겹쳐 보기와 나란히 보기 중에서 고를 수 있습니다.
- 선택한 한도가 응답에 빠져도 자리를 유지합니다. 다른 한도나 0%로 대신 표시하지 않습니다.
