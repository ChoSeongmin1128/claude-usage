# 2.5.3

## Codex 로그인과 사용량

- CLI에서 로그인 계정을 바꾼 뒤 새로고침하면 현재 계정의 사용량을 다시 확인합니다.
- 이전 계정의 늦은 조회 결과가 새 계정 화면에 반영되지 않도록 수정했습니다.
- 로그인 갱신은 공식 Codex CLI에 맡기며 ClaudeUsage가 CLI 인증 파일을 직접 수정하지 않습니다.
- 사용량과 한도 초기화 크레딧에 같은 계정 정보를 사용하고, 계정이 바뀌면 알림의 사용량 기준도 새로 시작합니다.
- 응답의 숫자 사용량 필드가 없거나 형식이 달라지면 0%로 표시하지 않습니다.

## 자동 조회

- 자동 조회 켜기·끄기와 주기 변경을 즉시 반영합니다.
- 서비스별 조회 주기와 배터리 절약 설정을 타이머에 일관되게 적용합니다.
- 중지하거나 교체한 타이머의 늦은 실행을 차단했습니다.

## 업데이트

- staging 업데이트를 `2.5.3-stg.2`처럼 검증 회차로 구분합니다.
- 같은 운영 예정 버전의 수정 후보도 새 빌드 번호에 따라 업데이트됩니다.
- 기존 계정 파일 형식과 표시 설정을 유지합니다.

## 알려진 제한

- Codex의 자동 로그인 복구에는 해당 계정 정보를 확인할 수 있는 공식 CLI가 필요합니다. CLI 설치·업데이트·로그인 상태에 따라 직접 확인이 필요할 수 있습니다.
- Antigravity IDE는 아직 지원하지 않습니다.
