# 2.5.3

## 업데이트 검증

- staging 업데이트를 `2.5.3-stg.1`처럼 검증 회차로 구분합니다.
- 같은 운영 예정 버전의 수정 후보도 새 빌드 번호에 따라 업데이트할 수 있도록 배포 절차를 개선했습니다.
- 기존 staging 배포본의 계정·표시 설정을 유지합니다. 이번 첫 후보의 사용량 조회 기능은 2.5.2와 같습니다.

## 알려진 제한

- Codex 인증 갱신과 CLI 로그인 변경이 겹치면 CLI 로그인에 영향을 줄 수 있는 문제가 남아 있습니다. 다음 수정 후보에서 검증할 예정입니다.
- 자동 조회 설정 변경이 즉시 반영되지 않는 문제도 다음 수정 후보에서 다룹니다.
- Antigravity IDE는 아직 지원하지 않습니다.
