# 2.10.0

## 처음 설정

- 시작하기 화면이 Claude, Codex, Antigravity마다 찾은 상태와 바로 할 일 하나를 보여줍니다.
- Claude는 Claude Code 로그인, 브라우저나 Claude 앱의 로그인 가져오기, 브라우저에서 새로 로그인, 앱 안 로그인 순으로 권합니다. 브라우저에서 새로 로그인하면 앱이 로그인을 알아채고 가져오기를 시작합니다.
- Codex와 AGY CLI에 로그인돼 있으면 바로 연결합니다. 설치되지 않았으면 ChatGPT 앱 다운로드나 터미널 설치 명령을 안내합니다. ChatGPT 앱에 들어 있는 Codex도 찾습니다.
- 팝오버의 Claude 다시 연결도 같은 순서를 따릅니다.

## 로그인 가져오기

- Chrome 외에 Brave, Edge, Whale, Vivaldi, Chromium, Firefox, Safari, Claude 앱에서 로그인을 가져옵니다. 기본 브라우저를 먼저 봅니다.
- 어느 브라우저에 로그인이 있는지 미리 볼 때는 확인 창을 띄우지 않습니다. 실제로 가져올 때 브라우저마다 한 번 확인합니다(Firefox는 확인 없음).
- Safari는 전체 디스크 접근 권한이 필요하며, 가져오기 창에서 설정을 열 수 있습니다.
- 앱 안 로그인은 방법 선택 없이 바로 Claude 로그인 페이지를 엽니다.

## Antigravity

- AGY CLI만 조회합니다. Antigravity 2.0 독립 앱은 공식으로 읽을 수 있는 사용량 경로가 없어 조회하지 않습니다. 이전에 독립 앱을 고른 설정은 AGY CLI로 바뀝니다.
