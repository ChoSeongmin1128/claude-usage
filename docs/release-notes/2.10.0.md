# 2.10.0

- 메뉴바 표시를 서비스별 프리셋으로 저장하고 다시 적용할 수 있습니다. 기본 제공 프리셋과 내 프리셋을 구분하고 이름 변경, 변경 저장과 삭제를 지원합니다. 세부 편집은 현재 메뉴바에 바로 반영하며 저장한 프리셋은 유지합니다.
- 서비스 설정에서 일반, 간소화와 호버의 표시 항목과 순서를 각각 고를 수 있습니다. Antigravity 호버는 직접 편집하기 전까지 현재 간소화 목록을 따릅니다. 항목을 모두 숨긴 선택도 유지합니다.
- 메뉴바 호버에서 선택한 사용량과 서비스 장애를 함께 확인합니다. 정상 상태는 이름 옆 상태점으로 표시하며, 조회 실패와 이전 값은 서비스 장애와 구분합니다. 긴 내용은 생략하지 않고 화면 높이 안에서 스크롤합니다.
- 호버 패널로 마우스를 옮겨 읽거나 스크롤할 수 있습니다. 아이콘과 패널을 벗어나거나 아이콘을 클릭하면 닫히며 앱 활성화나 키보드 포커스를 가져가지 않습니다. 클릭 팝오버의 일반/간소화 보기는 유지합니다.
- 설정, 팝오버, 연결 안내, 업데이트와 변경 내역의 글자, 간격과 선택 상태를 공통 디자인 규칙으로 정리했습니다. macOS의 표면과 기본 컨트롤을 사용하며 밝은/어두운 화면을 시스템 설정에 맞춥니다.
- 업데이트의 '지금 확인'에 새로고침 아이콘을 추가하고 다운로드부터 설치 준비까지 동작 버튼의 자리를 유지합니다. 새 기능 안내와 긴 변경 내역은 스크롤해서 읽을 수 있습니다.
- 새 프리셋/호버 저장 항목은 현재 채널에서 관리합니다. 읽지 못한 자료와 새 버전의 추가 필드를 보존하며, 기본값 복원은 저장한 내 프리셋을 유지합니다.
