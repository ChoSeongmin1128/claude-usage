# 2.10.1

- Claude Code와 Codex 기본 로그인 전환에서 선택한 사용자와 조직을 전후 확인합니다. 전환이 중단되면 보안 저장소의 복구 기록과 실제 로그인 자료를 대조하며, 외부에서 바뀐 자격은 임의로 덮어쓰지 않습니다.
- 앱이 직접 갱신하는 이전 Claude 로그인 사본은 갱신 요청과 새 자격을 영속 보존합니다. 처리 결과가 불확실한 이전 토큰은 다시 사용하지 않으며, 필요한 경우 기존 계정 연결 화면에서 다시 연결하도록 안내합니다.
- 손상된 알림, 계정과 팝오버 설정이 다른 서비스의 정상 설정을 초기화하지 않도록 보존 범위를 나눴습니다. 중복 계정 ID가 충돌하면 해당 항목을 보존하고 정상 계정만 사용합니다.
- 간소화 팝오버에서도 다른 계정의 이전 값과 보관 상태, 마지막 성공 시각을 표시합니다. 잘못된 Codex 한도 기간은 해당 한도만 제외하며 다른 정상 한도와 크레딧은 유지합니다.
- 모든 데이터 초기화가 끝날 때까지 실행 잠금을 유지합니다. 미완료 자격 복구 기록은 자동 적용을 중지한 뒤 보존하며, 준비를 확인하지 못하면 초기화를 시작하지 않습니다.
