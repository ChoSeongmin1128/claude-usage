# 2.6.0

## 일관된 사용량 표시

- 공통 표시 기준에서 사용한 양·남은 양을 선택하면 메뉴바·팝오버·알림 문구가 함께 바뀝니다. 신규 설치는 남은 양으로 시작하고, 기존 사용자는 공통 기준을 선택하기 전까지 이전 선택을 유지합니다. 주의 색상은 같은 위험도를 유지합니다.
- 메뉴바의 클래식·새 디자인을 선택할 수 있습니다. 기존 사용자의 외관은 클래식으로 유지하고 새 디자인을 한 번 소개합니다. 신규 설치는 새 디자인으로 시작하며 색상·표시 항목 설정은 보존합니다.
- 새 디자인의 배터리·원형·동심원·이중 배터리를 정리했습니다. 모노크롬 배터리의 글자, 투명 표현, 몸통과 단자 비율을 macOS 메뉴바에 더 가깝게 맞췄습니다.
- 제공되지 않은 한도는 0% 사용이나 100% 남음으로 표시하지 않습니다.

## 화면과 조작

- 팝오버 배경을 macOS 기본 재질에 맞추고, 본문과 하단 버튼의 간격을 정리했습니다.
- 사용량·서비스 상태 버튼에 외부 페이지 이동 표시를 추가하고 도움말과 접근성 설명을 개선했습니다.
- 선택한 서비스만 배경과 테두리로 강조합니다. 사용·남음 안내는 해당 비율 바로 옆에 표시합니다.
- 일반 설정의 전체 모션을 즉시·부드러움·사용자 설정으로 선택할 수 있습니다. 팝오버 열기·닫기와 크기, 설정 탭·빠른 시작 단계, 상세 접기·펼치기, 표시 항목 이동·숨기기, 사용량 막대 갱신을 개별 조절합니다. 기본값은 즉시이며 시스템의 동작 줄이기를 우선합니다.
- 설정의 계정 상세·고급 진단은 제목 행 전체를 눌러 펼칠 수 있습니다. 계정 선택과 상세 펼침은 독립적으로 동작합니다.
- Claude·Codex 연결 화면의 중복 정보와 카드를 정리했습니다. 디자인 비교와 짧은 선택 항목은 창 폭에 따라 가로 또는 세로로 배치합니다.
- 모션은 전체 선택기와 비교 영역 하나로 간소화했습니다. 개별 항목은 사용자 설정에서만 표시합니다. 디자인 선택은 현재 스타일을 간결하게 보여주며, 전체 스타일 비교를 펼쳐 다섯 모양을 확인할 수 있습니다.
- 알림 설정의 반복 설명을 정리하고 ‘알릴 시점’을 직접 입력하도록 개선했습니다. 사용 85%와 남음 15%처럼 표시 기준을 바꿔도 실제 알림 조건과 활성 상태를 유지합니다.
- 실제 조회된 한도별로 알림 대상을 선택할 수 있습니다. Claude 모델별 주간 한도, Codex의 기본·추가 모델별 시간 창, Antigravity 한도를 지원합니다. 기존 선택은 이전하며 새로 발견된 한도는 자동 활성화하지 않습니다. 크레딧 잔액과 초기화권은 알림 대상에서 제외합니다. Fable처럼 모델 ID가 없는 정상 응답도 지원하며 같은 이름으로 구분할 수 없는 항목만 제한합니다.
- 메뉴바·팝오버에서 한도를 숨겨도 알림 선택은 유지합니다. 일시적으로 미제공된 한도의 선택도 보존합니다.
- Antigravity 간소화 보기의 초기화 시간을 Claude·Codex와 같은 한 줄 행과 시간 규칙으로 표시합니다. 모델군에 주간 한도 하나만 있으면 중복되는 주간 표기를 생략하며, 여러 주기가 있으면 구분을 유지합니다.
- 메뉴바 직접 설정에 실제 미리보기를 추가하고 로고·게이지·안쪽 및 바깥 숫자·초기화 시간으로 구분했습니다. 관련 하위 옵션은 필요한 경우에만 표시합니다.
- 새 배터리의 숫자 간격과 픽셀 정렬을 조정하고, 글자 가장자리를 겹쳐 그리지 않도록 정리했습니다.
- 부드러운 팝오버 크기 전환 중에도 헤더와 하단 버튼을 유지하고, 연속 전환과 닫기가 겹칠 때 화면이 남는 문제를 수정했습니다.
- 신규 설치의 빠른 시작을 서비스 선택·연결 및 실제 조회 확인·메뉴바 설정으로 구성했습니다. 기존 사용자는 다시 로그인하거나 전체 안내를 반복할 필요가 없습니다.
- 미게시 검증 앱에는 beta와 빌드 번호를, 정식 staging 앱에는 해당 후보 번호를 표시합니다.
- 설정·서비스 연결·로그인·초기 설정 화면의 글자, 간격, 안내 패널을 통일했습니다.
- 메뉴바의 밝고 어두운 배경에 맞춰 게이지를 그리며, 동작 줄이기 설정을 반영합니다.

## 조회와 계정 전환

- 팝오버 새로고침 버튼과 `⌘R`이 선택한 서비스의 조회 상태와 재시도 대기 시간을 따릅니다.
- 추가 사용량은 같은 계정의 일시적 실패에 마지막 값과 확인 시각을 유지하고 이전 값임을 표시합니다. 계정 전환 후 이전 계정의 늦은 응답은 표시하지 않습니다.
- 로그인 창을 닫거나 다른 방법으로 돌아간 뒤 이전 작업의 결과가 화면을 바꾸지 않도록 수정했습니다.
- 기존 계정과 표시 설정을 유지하며 macOS 최소 요구 사항은 14입니다.
