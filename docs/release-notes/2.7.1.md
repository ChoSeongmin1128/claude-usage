# 2.7.1

## 요금제에 따른 사용량 표시

- Claude 응답에 5시간 한도가 없거나 비어 있으면(사용량 기반 Enterprise 등) 조회 전체가 "응답 형식 변경"으로 실패하던 문제를 해결했습니다. 응답에 있는 한도만 표시하고, 5시간 한도가 없으면 메뉴바는 주간 값으로 대신 표시합니다.
- Codex 응답에 5시간과 주간 한도가 모두 없거나(크레딧만 쓰는 Enterprise/Edu 유연 요금제) 한도 하나의 형식만 잘못돼도 조회 전체가 실패하던 문제를 해결했습니다. 표시할 값이 없으면 0% 대신 "—"를 보여줍니다.
- Claude가 한도 목록(`limits`)으로만 보내는 5시간·주간 한도와, 모델이 아닌 사용처 단위 주간 한도도 표시합니다.
- 메뉴바 툴팁과 "동시 표시"에 응답에 없는 한도를 "—"로 붙이지 않습니다.
- 조직 요금제 판정(알림 줄이기, 조직 자동 선택)이 요금제 이름에 특정 글자가 들어 있기만 하면 조직으로 보던 문제를 고쳤습니다. 이제 서버가 쓰는 정해진 값으로만 판정합니다.

## Codex 크레딧과 월 한도

- Codex 크레딧을 달러로 표시하던 문제를 고쳤습니다. 이제 개수로 표시합니다(예: 62,500 크레딧).
- Business/Enterprise 좌석의 월 크레딧 한도를 팝오버에 표시합니다. 워크스페이스 크레딧이 떨어졌거나 한도에 걸리면 그 이유를 메뉴바 툴팁에 함께 보여줍니다.

## Claude 추가 사용량

- 추가 사용량 금액을 계정 통화와 그 통화의 소수 자릿수로 표시합니다.
- 월 한도가 없으면 "$0.00 한도" 대신 "한도 없음"으로 표시하고, 사용률 대신 사용 금액을 보여줍니다.
- 추가 사용량 크레딧이 소진되면 "크레딧 소진"을 함께 표시합니다.

## 로그인과 데이터 정리

- "Claude.ai에서 직접 로그인"이 로그인 페이지를 보여주기도 전에 "세션 키가 유효하지 않습니다"로 실패하던 문제를 해결했습니다.
- Chrome에서 로그아웃된 상태로 가져오기를 하면 로그인 전 쿠키를 로그인 값으로 저장하던 문제를 고쳤습니다. 이제 "로그인 정보를 찾지 못함"으로 안내합니다.
- Claude 웹 계정을 지우면 그 계정의 표시 정보와 캐시도 함께 지웁니다. 이전 버전에서 지운 계정의 자료는 업데이트 후 첫 실행에서 정리합니다.
