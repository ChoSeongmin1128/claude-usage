# 2.9.4

- 계정을 전환하기 전에 옮길 로그인이 실제로 그 계정의 것인지 확인합니다. 다른 계정의 로그인이거나 확인하지 못하면 전환하지 않습니다.
- 다른 폴더로 로그인한 Claude Code 계정을 경로 끝의 '/'나 링크 경로로 로그인한 경우에도 찾습니다.
- 만료된 로그인을 바로 갱신하지 못하거나 네트워크, 서버 오류가 나면 로그인 필요로 바꾸지 않고 마지막 사용량을 유지합니다. 이전 값 표시는 Claude, Codex, AGY 모두 조회가 연속 2번 실패했을 때부터 붙습니다.
- Codex나 다른 Claude 계정이 요청 제한을 알려 주면 그 시간 동안 다시 요청하지 않습니다.
- 설정 창을 닫을 때 직접 고른 조직이 자동 선택으로 바뀌던 문제를 수정했습니다.
- 읽지 못한 설정과 계정 저장값을 기본값으로 덮어쓰지 않습니다. 이후 버전에서 2.9.4로 되돌려도 새 버전의 설정이 남습니다.
- 앱 초기화는 Claude Code 로그인에서 가져온 토큰 사본을 지웁니다. AGY 알림은 지금 AGY CLI에 로그인한 계정을 기준으로 보내고, 앱을 막 켰을 때 AGY 진단을 '설치 안 됨'으로 표시하지 않습니다.
