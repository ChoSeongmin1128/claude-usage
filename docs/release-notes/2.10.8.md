# 2.10.8

- 팝오버의 사용량 막대에 한도 기간 중 지난 시간의 위치를 세로 눈금으로 표시합니다. 채움과 눈금을 비교해 시간보다 빨리 쓰고 있는지 알 수 있습니다.
- 남은 양 기준에서는 눈금도 남은 시간 위치로 바뀝니다. 막대에 마우스를 올리면 경과 시간 또는 남은 시간의 비율을 보여 줍니다.
- Claude 5시간·주간·모델별 한도, 창 길이를 알리는 Codex 한도, Antigravity 5시간·주간 한도에 표시합니다. 창 길이를 알 수 없는 한도에는 표시하지 않습니다.
- 설정 → 표시 → 팝오버의 ‘경과 시간 눈금’에서 끌 수 있습니다. 기본은 켜져 있습니다.
