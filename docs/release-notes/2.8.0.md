# 2.8.0

## 여러 계정

- 설정 → 계정에서 Claude와 Codex 계정을 추가할 수 있습니다. 2개째가 연결되면 팝오버가 여러 계정 화면으로 바뀌고, 1개면 지금 화면 그대로입니다.
- 같은 계정이 기본 로그인, 다른 CLI 폴더, 앱의 웹 로그인으로 여러 번 보이면 계정과 조직이 같을 때 한 줄로 합치고 배지(사용 중, CLI, 웹)를 함께 붙입니다. 배지에 마우스를 올리면 뜻이 나옵니다.
- 팝오버 보기는 골라 보기(기본), 대표 카드와 목록, 요약과 행 중에 고릅니다. 골라 보기는 처음에 사용 중 계정과 다음 계정 하나를 보여주고, 고른 조합을 기억합니다.
- 메뉴바는 지금처럼 사용 중 계정 하나만 보여줍니다.
- 쓰지 않는 계정은 5분마다 확인합니다. 두 번 연속 실패해야 "오래된 값"으로 표시하고, 로그인 만료는 바로 알려줍니다. 계정마다 확인 시각을 보여줍니다.
- 계정마다 이름 바꾸기, 맨 위 고정, 숨기기, 조회 멈추고 보관을 할 수 있습니다. 숨긴 계정은 지우지 않습니다.
- 같은 이메일이 여러 조직에 있을 때만 이름 뒤에 조직을 붙입니다.

## 계정을 찾는 곳

- Claude: 기본 Claude Code 로그인, 앱에 저장한 웹 로그인, `~/.claude-이름`처럼 둔 CLAUDE_CONFIG_DIR 폴더, 직접 고른 폴더.
- 다른 폴더의 Claude Code 토큰이 곧 끝나면 그 폴더의 Claude Code가 갱신하게 합니다(`claude -p /usage`, 모델 호출 없음). Keychain에 저장된 폴더는 처음 한 번 macOS 확인이 필요합니다.
- Codex: 기본 `~/.codex`, `~/.codex-이름` 폴더, 앱이 만든 폴더, 직접 고른 폴더. 새 계정은 앱이 만든 폴더에서 공식 `codex login --device-auth`로 로그인하며 `~/.codex`는 바꾸지 않습니다. 폴더 사이에 로그인 파일을 복사하지 않습니다.

## 계정 전환

- 설정 → 계정에서 다른 폴더에 로그인해 둔 계정을 기본 로그인으로 바꿀 수 있습니다(계정 ⋯ → 이 계정으로 전환).
- 전환은 기본 로그인과 그 폴더의 로그인을 맞바꿉니다. 로그인 정보를 복사하지 않으므로 같은 로그인이 두 곳에 남지 않습니다.
- Claude Code는 Claude Code와 같은 잠금을 잡은 뒤 로그인을 다시 읽고 바꿉니다. macOS가 Keychain 사용을 물을 수 있으며, 실행 중인 Claude Code는 30초 안에 새 로그인을 씁니다. 바꾼 뒤 `claude auth status`로 확인하고 다르면 되돌립니다.
- Codex는 실행 중인 Codex(ChatGPT 앱이나 터미널)가 있으면 "종료하고 전환"과 "취소"만 고를 수 있습니다. 바꾼 뒤 공식 app-server로 계정을 확인하고 다르면 되돌립니다.
- 앱이 바꾼 기본 로그인이 나중에 다른 계정으로 돌아가 있으면 알림으로 알려줍니다.

## 한도 초기화권

- Claude와 Codex가 주는 한도 초기화권을 팝오버에 표시합니다. 개수, 지우는 범위(전체 한도 또는 5시간 한도만), 만료까지 남은 시간을 보여주고, 서버가 붙인 이름은 마우스를 올리면 보입니다.
- 새로 받은 초기화권에는 "신규"를 붙이고, 48시간 안에 만료되면 "곧 만료"로 알려줍니다. 한도에 도달했을 때는 쓰면 한도가 다시 채워진다는 안내를 덧붙입니다.
- 메뉴바 수치 옆에 ↺1처럼 개수를 표시할 수 있습니다. 새로 받으면 파란색, 곧 만료되면 빨간색입니다. 설정 → 한도의 초기화권 줄에서 항상, 신규나 곧 만료일 때만, 끔 중에 고릅니다. 업데이트한 사용자는 끔으로 시작하며 새 기능 안내에서 바로 켤 수 있습니다.
- 앱은 초기화권을 읽기만 하고 사용하지 않습니다.
- Codex 초기화권은 비공식 웹 경로 대신 설치된 Codex의 공식 app-server에서 읽고, 5분마다 한 번만 확인합니다.

## 처음 설정

- 시작하기 화면이 Claude, Codex, Antigravity마다 찾은 상태와 바로 할 일 하나를 보여줍니다.
- Claude는 Claude Code 로그인, 브라우저나 Claude 앱의 로그인 가져오기, 브라우저에서 새로 로그인, 앱 안 로그인 순으로 권합니다. 브라우저에서 새로 로그인하면 앱이 로그인을 알아채고 가져오기를 시작합니다.
- Codex와 AGY CLI에 로그인돼 있으면 바로 연결합니다. 설치되지 않았으면 ChatGPT 앱 다운로드나 터미널 설치 명령을 안내합니다. ChatGPT 앱에 들어 있는 Codex도 찾습니다.
- 팝오버의 Claude 다시 연결도 같은 순서를 따릅니다.

## 로그인 가져오기

- Chrome 외에 Brave, Edge, Whale, Vivaldi, Chromium, Firefox, Safari, Claude 앱에서 로그인을 가져옵니다. 기본 브라우저를 먼저 봅니다.
- 어느 브라우저에 로그인이 있는지 미리 볼 때는 확인 창을 띄우지 않습니다. 실제로 가져올 때 브라우저마다 한 번 확인합니다(Firefox는 확인 없음).
- Safari는 전체 디스크 접근 권한이 필요하며, 가져오기 창에서 설정을 열 수 있습니다.
- 앱 안 로그인은 방법 선택 없이 바로 Claude 로그인 페이지를 엽니다.
- 앱 안 로그인이 로그인 페이지를 보여주기도 전에 "세션 키가 유효하지 않습니다"로 실패하던 문제를 해결했습니다.
- 브라우저에서 로그아웃된 상태로 가져오기를 하면 로그인 전 쿠키를 로그인 값으로 저장하던 문제를 고쳤습니다. 이제 "로그인 정보를 찾지 못함"으로 안내합니다.

## 설정 구조

- 설정을 일반, 계정, 한도, 모양, 업데이트 다섯 패널로 나누고 macOS 기본 사이드바로 바꿨습니다.
- 한도 패널의 표에서 한도마다 메뉴바(숫자 표시), 팝오버, 알림을 한 줄에서 고릅니다. 게이지 모양과 대표 한도는 모양 패널에서 정합니다.
- 서비스별 계정 설정은 계정 패널에서 서비스를 골라 엽니다. 이전 버전에서 마지막으로 연 서비스 탭은 계정 패널의 그 서비스로 이어집니다.
- 빠른 시작은 마칠 때까지 사이드바에 남습니다.

## 시간 표시

- 시간 형식을 모든 서비스가 함께 씁니다. 일반 패널에서 고릅니다. 서비스마다 다르게 고른 경우 Claude 설정 값으로 맞추고 업데이트 안내에 알려줍니다.
- 남은 시간을 1:23처럼 짧게 보는 형식과, 주간 한도를 3d 02:12로 보는 형식을 추가했습니다.
- "현재 세션"을 "5시간 한도"로 부릅니다.

## 자동 확인

- 정해진 주기 대신 사용 상황에 맞춰 확인합니다. 팝오버를 막 열었거나 Claude Code, Codex를 쓰는 중이거나 한도가 10% 이하로 남으면 2분마다, 오래 쓰지 않으면 최대 30분 간격으로 확인합니다. 한도가 초기화된 직후에 한 번 더 확인합니다.
- 팝오버를 열거나 서비스를 바꿀 때 마지막 확인이 2분보다 오래됐으면 바로 확인합니다.
- 새로고침은 방금 갱신한 직후 10초 동안 요청하지 않고, 서버가 재시도 대기를 요청하면 그동안 버튼을 막고 남은 시간을 보여줍니다.
- 기존 갱신 주기와 배터리 사용 시 주기 설정은 정리했습니다. "사용량 자동 확인" 켜기/끄기는 그대로입니다.

## 요금제에 따른 사용량 표시

- Claude 응답에 5시간 한도가 없거나 비어 있으면(사용량 기반 Enterprise 등) 조회 전체가 "응답 형식 변경"으로 실패하던 문제를 해결했습니다. 응답에 있는 한도만 표시하고, 5시간 한도가 없으면 메뉴바는 주간 값으로 대신 표시합니다.
- Codex 응답에 5시간과 주간 한도가 모두 없거나(크레딧만 쓰는 Enterprise/Edu 유연 요금제) 한도 하나의 형식만 잘못돼도 조회 전체가 실패하던 문제를 해결했습니다. 표시할 값이 없으면 0% 대신 "—"를 보여줍니다.
- Claude가 한도 목록(`limits`)으로만 보내는 5시간·주간 한도와, 모델이 아닌 사용처 단위 주간 한도도 표시합니다.
- 메뉴바 툴팁과 "동시 표시"에 응답에 없는 한도를 "—"로 붙이지 않습니다.
- 조직 요금제 판정(알림 줄이기, 조직 자동 선택)이 요금제 이름에 특정 글자가 들어 있기만 하면 조직으로 보던 문제를 고쳤습니다. 이제 서버가 쓰는 정해진 값으로만 판정합니다.
- 0%보다 크면 1% 이상으로, 100%보다 작으면 99% 이하로 표시합니다. 반올림으로 다 쓰지 않았는데 100%로 보이는 일이 없습니다.

## Codex 크레딧과 월 한도

- Codex 크레딧을 달러로 표시하던 문제를 고쳤습니다. 이제 개수로 표시합니다(예: 62,500 크레딧).
- Business/Enterprise 좌석의 월 크레딧 한도를 팝오버에 표시합니다. 워크스페이스 크레딧이 떨어졌거나 한도에 걸리면 그 이유를 메뉴바 툴팁에 함께 보여줍니다.
- Business, Enterprise, Edu 요금제의 Codex 크레딧 행에 OpenAI 공식 요금표 링크를 붙였습니다.

## Claude 추가 사용량

- Claude Code로 연결한 계정도 추가 사용량을 표시합니다.
- 추가 사용량 금액을 계정 통화와 그 통화의 소수 자릿수로 표시합니다.
- 월 한도가 없으면 "$0.00 한도" 대신 "한도 없음"으로 표시하고, 사용률 대신 사용 금액을 보여줍니다.
- 추가 사용량 크레딧이 소진되면 "크레딧 소진"을 함께 표시합니다.

## Antigravity

- AGY CLI만 조회합니다. Antigravity 2.0 독립 앱은 공식으로 읽을 수 있는 사용량 경로가 없어 조회하지 않습니다. 이전에 독립 앱을 고른 설정은 AGY CLI로 바뀝니다.
- AGY CLI 사용량 보고를 낮은 우선순위로 실행합니다.

## 모양과 데이터 정리

- macOS의 "동작 줄이기"가 켜져 있으면 모션 선택을 막고 손쉬운 사용 설정으로 가는 버튼을 보여줍니다.
- Claude 웹 계정을 지우면 그 계정의 표시 정보와 캐시도 함께 지웁니다. 이전 버전에서 지운 계정의 자료는 업데이트 후 첫 실행에서 정리합니다.

## 업데이트 안내

- 새 기능이 있는 버전으로 업데이트하면 짧은 안내를 한 번 보여줍니다. 업데이트 패널의 "새 기능 다시 보기"로 다시 볼 수 있습니다. 새로 설치하면 보이지 않습니다.
