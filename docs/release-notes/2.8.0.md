# 2.8.0

## 설정 구조

- 설정을 일반, 계정, 한도, 모양, 업데이트 다섯 패널로 나누고 macOS 기본 사이드바로 바꿨습니다.
- 한도 패널의 표에서 한도마다 메뉴바(숫자 표시), 팝오버, 알림을 한 줄에서 고릅니다. 게이지 모양과 대표 한도는 모양 패널에서 정합니다.
- 서비스별 계정 설정은 계정 패널에서 서비스를 골라 엽니다. 이전 버전에서 마지막으로 연 서비스 탭은 계정 패널의 그 서비스로 이어집니다.
- 빠른 시작은 마칠 때까지 사이드바에 남습니다.

## 시간 표시

- 시간 형식을 모든 서비스가 함께 씁니다. 일반 패널에서 고릅니다. 서비스마다 다르게 고른 경우 Claude 설정 값으로 맞추고 업데이트 안내에 알려줍니다.
- 남은 시간을 1:23처럼 짧게 보는 형식과, 주간 한도를 3d 02:12로 보는 형식을 추가했습니다.
- "현재 세션"을 "5시간 한도"로 부릅니다.

## 자동 확인

- 정해진 주기 대신 사용 상황에 맞춰 확인합니다. 팝오버를 막 열었거나 Claude Code, Codex를 쓰는 중이거나 한도가 10% 이하로 남으면 2분마다, 오래 쓰지 않으면 최대 30분 간격으로 확인합니다. 한도가 초기화된 직후에 한 번 더 확인합니다.
- 팝오버를 열거나 서비스를 바꿀 때 마지막 확인이 2분보다 오래됐으면 바로 확인합니다.
- 새로고침은 방금 갱신한 직후 10초 동안 요청하지 않고, 서버가 재시도 대기를 요청하면 그동안 버튼을 막고 남은 시간을 보여줍니다.
- 기존 갱신 주기와 배터리 사용 시 주기 설정은 정리했습니다. "사용량 자동 확인" 켜기/끄기는 그대로입니다.
- AGY CLI 사용량 보고를 낮은 우선순위로 실행합니다.

## 표시

- 0%보다 크면 1% 이상으로, 100%보다 작으면 99% 이하로 표시합니다. 반올림으로 다 쓰지 않았는데 100%로 보이는 일이 없습니다.
- Claude Code로 연결한 계정도 추가 사용량을 표시합니다.
- Business, Enterprise, Edu 요금제의 Codex 크레딧 행에 OpenAI 공식 요금표 링크를 붙였습니다.
- macOS의 "동작 줄이기"가 켜져 있으면 모션 선택을 막고 손쉬운 사용 설정으로 가는 버튼을 보여줍니다.

## 업데이트 안내

- 새 기능이 있는 버전으로 업데이트하면 짧은 안내를 한 번 보여줍니다. 업데이트 패널의 "새 기능 다시 보기"로 다시 볼 수 있습니다. 새로 설치하면 보이지 않습니다.
