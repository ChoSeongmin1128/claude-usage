# 2.8.2

- Claude 브라우저 계정의 추가 사용량이 기본 사용량과 함께 갱신됩니다.
- 팝오버와 조직 미리보기가 사용량 응답의 같은 사용액과 한도를 우선 표시합니다.
- 초기화권 개수가 줄기만 하거나 상세 정보가 늦게 도착해도 신규로 표시하지 않습니다. 계정별로 구분하며 초기화권 행을 보고 닫았을 때 확인 처리합니다.
- Codex 사용량과 초기화권 개수를 먼저 표시한 뒤 상세 정보를 확인합니다. 상세 조회가 실패해도 개수를 유지하고 다음 조회에서 다시 확인합니다. 이전 정보와 일부 누락, 만료 없음과 정보 없음을 구분합니다.
- Fable과 Codex 추가 모델 한도를 메뉴바 숫자, 초기화 시간과 게이지로 고를 수 있습니다. Antigravity도 조회된 각 한도의 숫자와 시간을 따로 고릅니다.
- 로그인 시 자동 시작을 켜도 등록 요청이 누락되던 경우를 수정했습니다. 정상 등록과 승인 대기, 등록 실패를 구분하고 시스템 설정에서 변경한 상태도 다시 확인합니다.
