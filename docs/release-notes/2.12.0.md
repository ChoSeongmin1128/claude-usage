# 2.12.0

## 계정 전환

- 설정 → 계정에서 다른 폴더에 로그인해 둔 계정을 기본 로그인으로 바꿀 수 있습니다(계정 ⋯ → 이 계정으로 전환).
- 전환은 기본 로그인과 그 폴더의 로그인을 맞바꿉니다. 로그인 정보를 복사하지 않으므로 같은 로그인이 두 곳에 남지 않습니다.
- Claude Code는 Claude Code와 같은 잠금을 잡은 뒤 로그인을 다시 읽고 바꿉니다. macOS가 Keychain 사용을 물을 수 있으며, 실행 중인 Claude Code는 30초 안에 새 로그인을 씁니다. 바꾼 뒤 `claude auth status`로 확인하고 다르면 되돌립니다.
- Codex는 실행 중인 Codex(ChatGPT 앱이나 터미널)가 있으면 "종료하고 전환"과 "취소"만 고를 수 있습니다. 바꾼 뒤 공식 app-server로 계정을 확인하고 다르면 되돌립니다.
- 앱이 바꾼 기본 로그인이 나중에 다른 계정으로 돌아가 있으면 알림으로 알려줍니다.
